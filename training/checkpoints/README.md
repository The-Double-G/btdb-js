# AI Checkpoints

`champion.json` is the repository audit mirror of the latest checked distributed promotion. It is not the training authority.

Each training generation starts from one immutable Hosted Model snapshot artifact. Distributed selection replaces only the selected schema-9 policy bundle, generation metadata, and bounded two-policy population history in that snapshot; shard-learned stores are not promoted. The policy bundle contains both the strategic network and shared neural candidate scorer. This audit checkpoint can therefore contain the public aggregate model fields present in the hosted GET response.

Never copy the private production state envelope into this directory. Contribution guards, identifiers, rate-limit records, tokens, secrets, and trainer or promotion authorization are prohibited.

Manual and continuous promotion replace only `champion.json` after the exact hosted snapshot and candidate pass frozen evaluation, hosted publication, and exact-commit CI.
